2. How the nesting works

Outer fold: evaluation

Example: historical training = Days 1–10; outer test = Day 11, Beep 1.

Inner folds: model selection

Repeatedly fit candidates on earlier observations and validate on later observations, using only the outer training history.

Select regularization

Compare alpha and lambda candidates using aggregated inner-validation loss.

Historical threshold selection

Use historical validation probabilities and labels to choose a decision cutoff, for example the cutoff maximizing MCC.

Final outer refit

Refit the chosen model on all eligible outer training observations.

Outer test: unseen future beep

Generate predicted nonresponse probabilities, apply the previously selected threshold, and record evaluation results.

5. Key terminology

Outer fold

One historical training window plus the next held-out assessment beep. It estimates the performance of the full modeling procedure on unseen data.

Inner fold

A smaller chronological train/validation split within the outer training window. It helps select model hyperparameters without looking at outer test labels.

Expanding window

Each successive fold retains earlier history and adds newly eligible observations. The training set grows over time.

Threshold selection

Choosing the cutoff that converts a predicted nonresponse probability into class 0 or class 1, using historical validation outcomes.
